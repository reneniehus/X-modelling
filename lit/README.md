# Reference literature for the modelling work

The methodological canon this project's modelling follows. Copyrighted PDFs are
deliberately **not** committed (this is a public repo) — keep personal copies locally;
`lit/*.pdf` is gitignored to prevent accidents.

- **Gelman, Vehtari, Simpson, Margossian, Carpenter, Yao, Kennedy, Gabry, Bürkner,
  Modrák (2020). "Bayesian workflow."** arXiv:2011.01808 —
  https://arxiv.org/abs/2011.01808
- **McElreath (2024). "Rethinking workflows."** Blog essay on making workflow the
  centre of the *Statistical Rethinking* 3rd edition — https://elevanth.org/blog/
- **McElreath (2020). *Statistical Rethinking: A Bayesian Course with Examples in R
  and Stan*, 2nd edition.** CRC Press — https://xcelab.net/rm/
  - Julia/Turing translation of all book models: see `Rethinking_Julia_translation`
    (https://github.com/Shmuma/rethinking-2ed-julia)
